# 📋 학원 출석부

학원 조교를 위한 모바일 출석 관리 앱입니다.
구글 스프레드시트와 연동되어 터치 한 번으로 출석/결석을 기록합니다.

---

## 🚀 처음 시작하기 (딱 한 번만!)

### 1단계. Node.js 설치
아직 설치하지 않았다면 → [nodejs.org](https://nodejs.org) 에서 **LTS** 버전 다운로드 후 설치

### 2단계. 설치하기
`학원-출석부` 폴더 안에서 **`설치하기.command`** 파일을 더블클릭

> ⚠️ "개발자를 확인할 수 없음" 경고가 뜨면?
> → 파일에서 **오른쪽 클릭** → **열기** → **열기** 클릭

잠시 기다리면 브라우저가 자동으로 열리고 설정 화면이 나타납니다.
화면의 안내를 따라 구글 시트를 연결하세요.

### 3단계. 매일 사용할 때
**`앱 시작하기.command`** 파일을 더블클릭하면 됩니다.

---

## 📱 기능 소개

| 기능 | 설명 |
|------|------|
| 전체 탭 | 학생 목록 + 출석/결석/미확인 터치로 상태 변경 |
| 결석 탭 | 결석 학생만 모아보기 |
| 전화하기 | 학부모/학생 전화번호로 바로 전화 연결 |
| 문자보내기 | 학부모/학생 전화번호로 문자 앱 실행 |
| 자동 저장 | 터치하면 즉시 구글 시트에 반영 |

## 📊 구글 스프레드시트 컬럼 구조

| A | B | C | D | E | F | G | H | I | J~ |
|---|---|---|---|---|---|---|---|---|-----|
| 이름 | 학교 | 수업유형 | 출처사 | 현황 | 시험범위 | 시험기간 | 학부모연락처 | 학생연락처 | 날짜(자동) |

- **J열부터** 날짜 컬럼이 자동으로 추가됩니다
- 값: `출석` / `결석` / 빈칸(미확인)

## ❓ 자주 묻는 질문

**Q. "개발자를 확인할 수 없음" 오류가 떠요**
A. 파일 오른쪽 클릭 → 열기 → 열기 를 누르세요.

**Q. 앱을 종료하고 싶어요**
A. 터미널 창(검정 창)을 닫으면 됩니다.

**Q. 스프레드시트가 업데이트 안 돼요**
A. 구글 시트 공유 설정에서 서비스 계정 이메일에 편집자 권한이 있는지 확인하세요.
